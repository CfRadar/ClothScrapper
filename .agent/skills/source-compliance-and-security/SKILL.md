# Source Compliance and Security

## Purpose
Establishes the security, compliance, and legal safeguards required when integrating third-party e-commerce, wholesale, and social platforms. Enforces an automated outbound SSRF host allowlist generated directly from `sources.yaml`, a strict per-source high-risk kill switch, and enhanced regex gating for apparel material phrases.

---

## When to Use
- Adding any new source adapter to `sources.yaml` or updating outbound host lists.
- Auditing terms of service risks (`tos_risk: low | medium | high`).
- Configuring environment safety flags (`SOURCES_ALLOW_HIGH_RISK`).
- Updating keyword gating regex patterns to permit fabric metrics ("100% cotton", "240 gsm").

---

## 1. Outbound Host Allowlist Generation

To prevent Server-Side Request Forgery (SSRF) and data exfiltration, the backend outbound HTTP client (`SafeAsyncClient`) and Playwright route interception **must only permit exact hosts declared in `sources.yaml`**:

```python
import yaml
from pathlib import Path

def load_allowlisted_hosts_from_registry(registry_path: str = "backend/app/scrapers/sources.yaml") -> set[str]:
    """
    Parses sources.yaml and compiles a strict, deduplicated set of permitted outbound hosts.
    Wildcards (e.g. *.domain.com) are strictly forbidden.
    """
    allowlist = {
        "openrouter.ai", # Core LLM provider
    }
    path = Path(registry_path)
    if not path.exists():
        return allowlist

    with open(path, "r", encoding="utf-8") as f:
        data = yaml.safe_load(f) or {}

    for src in data.get("sources", []):
        for host in src.get("hosts", []):
            clean_host = host.strip().lower()
            if clean_host and not clean_host.startswith("*"):
                allowlist.add(clean_host)

    return allowlist
```

### Constraints:
- **No Wildcards**: Every subdomain (e.g. `completion.amazon.in`, `dir.indiamart.com`) must be listed explicitly.
- **DNS Verification**: IP addresses resolved from these domains must be validated to ensure they are public addresses (reject `127.0.0.1`, `10.0.0.0/8`, `192.168.0.0/16`, `169.254.169.254`).

## 2. Per-Source Kill Switch & High-Risk Gating

Sources marked with `tos_risk: "high"` (e.g. Alibaba, Meta Ad Library) require explicit administrative consent to operate:

1. **Environment Flag**:
   In `backend/.env`:
   ```bash
   SOURCES_ALLOW_HIGH_RISK=false
   ```
2. **Execution Check**:
   Before dispatching any high-risk scrape:
   ```python
   if source.tos_risk == "high" and not settings.SOURCES_ALLOW_HIGH_RISK:
       return SourceResult(
           source_id=source.id,
           status="disabled",
           strategy_used="none",
           note="High-risk source disabled by administrator policy (SOURCES_ALLOW_HIGH_RISK=false)."
       )
   ```
3. **UI Acknowledgement**:
   If an operator attempts to enable a high-risk source through the frontend "Sources" popover, the UI must render an amber warning badge and require a modal confirmation acknowledging platform terms.

## 3. Terms of Service & Legal Disclosures

Document the following principles in `SECURITY.md` and `README.md`:
- Scraping public retail listings, autosuggestions, and social posts may conflict with certain platform terms of service.
- **Zero Stealth Policy**: The application operates transparently, respects rate limits, never rotates proxies, never solves CAPTCHAs, and immediately yields (`status="blocked"`) upon encountering any bot challenge.
- The system harvests search keywords and strategic metadata only; it never copies full copyrighted catalogs, images, or customer user reviews.

## 4. Enhanced Keyword Gating Regex

All candidate keywords extracted by adapters or generated by LLMs must pass through `gate_keywords()`. The gating regex is expanded to support critical apparel attributes (percentages, fabric weights, fractions):

```python
import re

# Permits alphanumeric phrases plus common fashion characters: %, +, &, ', -, ., /
# Examples allowed: "100% cotton", "240 gsm", "black & white", "3/4 sleeve", "heavy-drape"
# Rejects: URLs (http, .com), HTML tags (<, >), email addresses, and instruction-like prompts
ENHANCED_KEYWORD_REGEX = re.compile(r"^[a-z0-9][a-z0-9 '&%+./-]{1,60}$")

def gate_keyword(candidate: str) -> str | None:
    norm = candidate.strip().lower()
    if not ENHANCED_KEYWORD_REGEX.match(norm):
        return None
    if any(blocked in norm for blocked in ("http://", "https://", "www.", ".com", "<script", "ignore previous")):
        return None
    return norm
```

## 5. Security Test Suite Requirements

Every newly registered source must have automated security tests added to `backend/tests/security/test_security.py`:
1. **Outbound SSRF Verification**: Ensure requests targeting non-declared domains are intercepted and rejected.
2. **Pincode Injection Defense**: Ensure quick-commerce pincode parameters reject command injection or non-digit characters (`110001; rm -rf` -> rejected).
3. **Endpoint Rate Limiting**: Ensure source configuration endpoints (`POST /api/sources/{id}/enable`) enforce IP rate limits and require `X-Run-Token`.
